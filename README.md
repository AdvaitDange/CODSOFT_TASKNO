## 🛠️ Projects Summary

### 🤖 Task 1: Chatbot with Rule-Based Responses
* **Domain**: Natural Language Processing (NLP) & Pattern Matching
* **Description**: A smart conversational assistant utilizing regular expressions, keyword tokenization, and intent classification trees.
* **Capabilities**: Handles greetings, user name memory, AI concepts, CodSoft internship FAQs, real-time date/time lookups, jokes, and guided fallback handling.
* **How to run**:
  ```bash
  cd Task_1_Rule_Based_Chatbot
  python chatbot.py
  ```

---

### 🎮 Task 2: Tic-Tac-Toe AI (Unbeatable Minimax Algorithm)
* **Domain**: Game Theory & Adversarial Search Algorithms
* **Description**: An unbeatable AI agent playing the classic game of Tic-Tac-Toe against a human player.
* **Algorithm**: Powered by the **Minimax Algorithm** with **Alpha-Beta Pruning**, searching the entire state space to make mathematically optimal moves.
* **Interfaces**:
  - **Tkinter GUI** (`tictactoe_gui.py`): Modern dark-mode GUI with scoreboard, difficulty toggle, and interactive buttons.
  - **CLI** (`tictactoe_cli.py`): Clean ASCII grid terminal gameplay.
* **How to run**:
  ```bash
  cd Task_2_Tic_Tac_Toe_AI
  python tictactoe_gui.py   # Launch GUI (Recommended for video demo)
  # OR
  python tictactoe_cli.py   # Launch CLI in terminal
  ```

---

### 🎬 Task 3 (PDF Task 4): Movie Recommendation System
* **Domain**: Machine Learning & Information Retrieval
* **Description**: A content-based movie recommender that suggests similar films based on user preferences.
* **Technique**: Constructs a weighted metadata soup (genres, keywords, plot overview, director), computes high-dimensional **TF-IDF vector representations**, and calculates **Cosine Similarity** rankings.
* **Features**: Fuzzy title lookup, similarity percentage scoring, top-N recommendations.
* **How to run**:
  ```bash
  cd Task_3_Movie_Recommendation_System
  python recommender.py
  ```
